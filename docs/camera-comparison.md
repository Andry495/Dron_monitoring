# Сравнение моделей камер

Дата: 2026-07-08  
Контекст: комплект **4× Sky + 4× PTZ** для наблюдения за небом.

Цены — **ориентир по открытым предложениям** в РФ (KNS, Dahua-shop, DSSL, ТЕКО, avshop и др.). Перед закупкой запросить КП у 2–3 поставщиков: разброс по PTZ может достигать **×2**.

---

## Критерии отбора

### Sky (фикс, 4 шт.)

| Критерий | Зачем |
|----------|--------|
| HFOV ≥ 100° @ 2.8 mm | Перекрытие секторов N/E/S/W с overlap 15–25% |
| 4 MP минимум | Движение + лёгкий `/detect` на субпотоке 720p |
| Матрица ≥ 1/2.8" | Чувствительность на контровом небе |
| IP67, RTSP, ONVIF | Улица, интеграция в core |
| Субпоток 720p | Нагрузка на ai-engine |

### PTZ (углы, 4 шт.)

| Критерий | Зачем |
|----------|--------|
| Optical zoom ≥ 25× | Классификация 300–700 m (дрон 0.5 m) |
| ONVIF GetStatus | Углы для триангуляции |
| Tilt до +90° | Home «▲ вверх» (зенит) |
| HFOV tele ≤ 3° | Дальность по пикселям |
| IP66, 12 V | Улица, питание без PoE в v1 |
| Скорость preset pan/tilt | Быстрое наведение после sky |

### Sky — вывод

| Вариант | Когда выбирать |
|---------|----------------|
| **DS-2CD2T47G2-L** | Оптимально по цене; проверенная связка с PTZ Hikvision |
| **DS-2CD2T86G2-4I** | Нужна большая дальность motion без смены PTZ; бюджет +30–50k на 4 шт. |
| **Dahua HFW2431S** | Экономия ~10–15% при готовности к чуть худшему SNR на небе |

**Рекомендация:** оставить **DS-2CD2T47G2-L**. Если бюджет позволяет — рассмотреть **DS-2CD2T86G2-4I** только на sky (PTZ не менять).

## 5. Итоговая рекомендация

**Менять v1 нет смысла**, если нет жёсткого требования по дальности:

1. **Sky:** **Hikvision DS-2CD2T47G2-L(2.8mm)** — оптимальны цена, матрица 1/1.8" и FOV.
2. **PTZ:** **Hikvision DS-2DE4A425IWG-E** — достаточно 25× для задачи; ONVIF и калибровка описаны в проекте.

**Имеет смысл пересмотреть**, если:

| Условие | Действие |
|---------|----------|
| Dahua SD49425 **>15% дешевле** Hikvision при той же гарантии | Заменить только PTZ → **DH-SD49425XB-HNR** |
| Нужно ловить мини-дроны **>150 m** на sky | Апгрейд sky → **DS-2CD2T86G2-4I(2.8)** |
| Нужна классификация **>700 m** | Апгрейд PTZ → **DS-2DE7A432IW-AEB** (32×) |
| Жёсткий бюджет на sky | **Dahua IPC-HFW2431S-S-S2** (с тестом на ярком небе) |
