# Баллистика турели — сеть до 50 m

Версия: **0.1** · дополнение к [turret.md](turret.md)

---

## 1. Система координат

| СК | Начало | Оси |
|----|--------|-----|
| **ENU** | база турели на площадке | E, N, U (м) |
| **LOS** | узел pan/tilt | az (от севера), el (от горизонта) |

Переход ENU → LOS (упрощённо, плоская земля):

```
range = √(E² + N² + U²)
az    = atan2(E, N)
el    = atan2(U, √(E² + N²))
```

Обратное наведение: `az_cmd`, `el_cmd` → цель в LOS.

## 2. Модель полёта снаряда-сети

### 2.1 Упрощённая (для проекта)

```
R ≈ v₀ × cos(φ) × t_flight
t_flight ≈ R / v_eff

v_eff = v₀ × k_drag(R)    # k_drag ∈ [0.85 … 0.95] на 50 m
```

| R (m) | v₀=30 m/s, k=0.9 | t_flight |
|-------|------------------|----------|
| 10 | | 0.37 s |
| 25 | | 0.93 s |
| 50 | | 1.85 s |

### 2.2 Раскрытие сети

```
t_go = t_flight + t_open + t_latency

t_open   — 0.15…0.35 s (измерить на полигоне)
t_latency — 0.03…0.08 s (камера 30fps + контроллер + клапан)
```

Центр сети в момент «полного раскрытия»:

```
p_net ≈ p_muzzle + v_muzzle × t_flight + ½ g t_flight²   (если учитывать баллистику)
```

Для малых R и почти горизонтального выстрела на небо часто достаточно **прямолинейной** модели по LOS.

## 3. Упреждение по движущейся цели

Состояние цели от core (ENU):

```
p(t) = p₀ + v × t + ½ a × t²     (a ≈ 0 или из фильтра)
```

Момент выстрела `t_fire`. Нужно:

```
p_net(t_fire + t_go) ≈ p_target(t_fire + t_go)
```

Итерация (1–3 шага):

```
1. R₀ = ‖p_target − p_muzzle‖
2. t_go = f(R₀)
3. p_aim = p_target(t_fire + t_go)
4. az_cmd, el_cmd = LOS(p_aim)
5. Уточнить R, повторить
```

### Угловое упреждение (локальная камера)

При известной дальности R и угловых скоростях `ω_az`, `ω_el` (rad/s):

```
Δaz = ω_az × t_go
Δel = ω_el × t_go
```

## 4. Зоны поражения

```text
        R < R_min          R_min … R_max              R > R_max
      ┌─────────────┬──────────────────────┬──────────────────┐
      │  ЗАПРЕТ      │   ЗОНА ПЕРЕХВАТА     │  только сопровожд.│
      │  (сеть не    │   FIRE разрешён     │  (core cue only)  │
      │   раскрылась)│                      │                   │
      └─────────────┴──────────────────────┴──────────────────┘
           ~8 m              до 50 m                 >50 m
```

| Зона | R | FIRE |
|------|---|------|
| Внутренняя | < **R_min** (8–12 m) | **Запрещён** — сеть не успевает раскрыться |
| Рабочая | **R_min … 50 m** | Разрешён при TRACK + класс |
| Внешняя | > 50 m | Только COARSE slew по core |

### Диаметр сети vs промах

| D_net | Допустимый промах центра (дрон 0.5 m) |
|-------|--------------------------------------|
| 2 m | ±0.75 m |
| 3 m | ±1.25 m |
| 5 m | ±2.25 m |

Требуемая точность наведения на **R=50 m**, D_net=3 m:

```
угловая ошибка < atan(1.25 / 50) ≈ 1.4°
```

С учётом упреждения — локальный контур должен держать **<0.5°** в момент FIRE.

## 5. Примеры (дрон 0.5 m, v=8 m/s)

| R | t_go ≈ | Поперечное смещение v×t_go | Примечание |
|---|--------|---------------------------|------------|
| 15 m | 0.55 s | 4.4 m | Упреждение критично |
| 30 m | 1.1 s | 8.8 m | Без TRACK невозможно |
| 50 m | 1.9 s | 15.2 m | На пределе; нужен точный v от PTZ |

Горизонтальная скорость **8 m/s** на **R=50 m** — реалистичный предел для v0.1 при v₀≈30 m/s.

## 7. Ограничения модели

- Ветер >5 m/s — пересмотр `t_go` или запрет FIRE.
- Цель за преградой (небо чистое в LOS) — запрет.
- Ускорение цели (дрон рывком) — расширить Kalman до `(vx, vy, vz, ax, ay, az)`.
- Ночь — зависит от камеры турели и подсветки; не в v0.1.

См. [turret.md](turret.md), [optics-and-range.md](optics-and-range.md).
