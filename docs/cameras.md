## 1b. Альтернатива куполу — 4× фиксированные камеры (панорама неба)

Вместо одного fisheye на верхней грани — **4 bullet/turret** с жёсткой ориентацией по сторонам куба (N/E/S/W). Каждая смотрит **вверх** с лёгким наклоном к своему сектору; **поля зрения перекрываются** на 15–25% для склейки треков.

```text
              ↑ небо
    [Sky-N]       [Sky-E]      ← 4 камеры на верхней грани
         \   ▲   /
          \  |  /              сектора ~90° + overlap
    [Sky-W]     [Sky-S]
        ═══════════════        верх куба
```

### Требования к обзору

| Параметр | Значение |
|----------|----------|
| Сектор на камеру | ~90° азимута (N / E / S / W) |
| Перекрытие с соседями | **15–25%** HFOV (для handoff трека) |
| Нужный HFOV | **≥ 100–110°** на камеру (2.8 mm на 1/2.8") |
| Наклон от зенита | **15–35°** к горизонту (настраивается кронштейном) |
| Зум | **Фикс** (без motor zoom) |

### Рекомендуемые модели (4 одинаковые)

| | **Основная** | **Альтернатива** | **Бюджет** |
|---|-------------|------------------|------------|
| **Модель** | **Hikvision DS-2CD2T47G2-L(2.8mm)** | **Dahua IPC-HFW2431S-S-S2(2.8mm)** | **Hikvision DS-2CD1023G2-LIU(2.8mm)** |
| MP | 4 MP ColorVu | 4 MP | 2 MP |
| Объектив | 2.8 mm фикс, ~105° HFOV | 2.8 mm фикс | 2.8 mm фикс |
| Улица | IP67 | IP67 | IP67 |
| Цена × 4 | **4 × 8–14k = 32–56k ₽** | **4 × 7–12k = 28–48k ₽** | **4 × 4–7k = 16–28k ₽** |

**Рекомендация:** **Hikvision DS-2CD2T47G2-L(2.8mm)** × 4 — дневное небо (ColorVu), нормальный HFOV, дешевле одного fisheye.

### Плюсы / минусы vs fisheye

| | 4× фикс | 1× fisheye |
|---|---------|------------|
| Цена | **Дешевле** (32–56k vs 38–52k) | 1 порт, проще калибровка |
| Дисторция | Меньше по краям кадра | Сильная, нужен dewarp |
| CPU | 4 субпотока 720p | 1 поток + dewarp |
| Трекинг | Склейка на overlap | Один кадр |
| Порты switch | **+3** (4 вместо 1) | 1 |
| Калибровка | 4× `sky_n/e/s/w` в `site.yaml` | 1× fisheye→az/el |

### ПО (ядро)

- `sky_watch` слушает **4 RTSP** параллельно.
- Детектор на каждом субпотоке; при overlap — **один `track_id`** (склейка по близким az/el).
- Угловые PTZ получают цель как сейчас.

### Порты switch (если 4 sky + 4 PTZ готовые)

| Устройство | Портов |
|------------|--------|
| 4× sky fixed | 4 |
| 4× PTZ угла | 4 |
| мини-ПК | 1 |
| **Итого** | **9** (+ резерв 11–12) |

## 2. Угловые камеры — вариант A: готовая PTZ (поворот + наклон + зум в корпусе)

ESP32 для pan/tilt **не нужен** — только 1 IP на угол.

### Основная PTZ

| | **Основная** | **Альтернатива** |
|---|-------------|------------------|
| **Модель** | **Hikvision DS-2DE4A425IWG-E** | **Dahua DH-SD49425XB-HNR** |
| Разрешение | 4 MP (2560×1440) | 4 MP |
| Оптический зум | **25×** (4.8–120 mm) | **25×** (4.8–120 mm) |
| Pan / Tilt | 360° / −5°…90° | 360° endless / −15°…90° |
| ONVIF PTZ status | Да | Да |
| Улица | IP66 | IP66 |
| Питание | 12 V DC, ~24 W | 12 V DC / PoE+ |
| Цена за 1 шт. | **42 000 – 58 000 ₽** | **48 000 – 72 000 ₽** |
| USD | ~$480–570 | ~$520–780 |
| **4 угла** | **168 000 – 232 000 ₽** | **192 000 – 288 000 ₽** |

**Рекомендация:** **Hikvision DS-2DE4A425IWG-E** — распространённая модель, 25× optical, DarkFighter, нормальный ONVIF. Перед заказом 4 шт. — **1 шт. на стенд**: проверить `GetStatus` pan/tilt/zoom и повторяемость после `goto preset`.

### Не брать для этого проекта

| Модель | Почему |
|--------|--------|
| Hikvision DS-2DE3A404IW-DE | 4× зум — мало для классификации на дистанции |
| No-name PTZ с AliExpress | Врут зум, слабый ONVIF, углы плывут |
| Wi‑Fi-версии PTZ | Нужен только RJ45 |

## 5. Что выгоднее по деньгам

| Вопрос | Ответ |
|--------|--------|
| **Дешевле всего выйти в поле?** | **Готовая PTZ Hikvision** (~253k) — без R&D, 5 IP вместо 9 |
| DIY дешевле PTZ? | **Только** с дешёвой IZS 2.8-12 (~243k) — **паритет**, не экономия |
| DIY с 8-32 mm? | **Дороже** готовой PTZ (~423k vs ~253k) |
| С учётом 100+ ч разработки? | **PTZ однозначно** |

### Итог

```
Лучший баланс цена / результат / срок:
  Небо:   4× Hikvision DS-2CD2T47G2-L(2.8mm)  ИЛИ  1× Dahua EBW81242
  Углы:   Hikvision DS-2DE4A425IWG-E × 4
  Итого:  ~250 000 ₽
```

DIY имеет смысл, если уже есть 3D-принтер, CAD и цель — **своя механика/энкодеры**, а не экономия.
