# Мёртвые зоны покрытия

Версия: **1.1** · 2026-07-08 · комплект **v1** (4× Sky + 4× PTZ)

> **Область применения:** расчёты и схемы ниже — для **`cube_compact`** ([site.example.yaml](../config/site.example.yaml)).  
> Для **`building_corners`** (углы здания + купол-hub) см. [deployment-building.md](deployment-building.md) §7.

Параметры по умолчанию (cube_compact):
- куб `half_size_m: 0.5`, высота постамента `1.2 m`
- Sky: HFOV **105°**, `mount_tilt_deg: 25`, overlap **20%**
- PTZ home: **зенит**; wide HFOV **53.3°**

## 1. Система координат

| Угол | Определение |
|------|-------------|
| **az** | Азимут от севера, 0° = N, по часовой |
| **el** | Угол места над горизонтом, 0° = горизонт, 90° = зенит |
| **R** | Наклонная дальность до цели |

Начало ENU — проекция **центра куба** на землю (для building_corners — центр купола-hub).

---

## 2. Классификация зон

| Код | Тип | Смысл |
|-----|-----|--------|
| **A** | Полный провал | Нет motion, нет PTZ, нет координат |
| **M** | Только motion | Sky или один PTZ wide; без стабильной геометрии |
| **C** | Motion + класс | PTZ наведён; класс есть |
| **G** | Motion + класс + geo | Триангуляция 2× PTZ, `pos_confidence` достаточен |
| **T** | Зона турели | R ≤ 50 m, перехват возможен (модуль опц.) |

## 3. Sky × 4 — мёртвые зоны

### 3.1 Геометрия сектора

Каждая Sky на середине грани, ось **отклонена на 25° от зенита** к своему азимуту (N/E/S/W).

```
Полуугол обзора:  HFOV/2 = 52.5°
Ширина сектора (номинал): 90° между осями
Полоса overlap:   20% × 105° ≈ 21° между соседями
```

| Направление | Покрытие Sky (номинал) |
|-------------|------------------------|
| N | az 327°…57° (через 0°) |
| E | az 57°…147° |
| S | az 147°…237° |
| W | az 237°…327° |

При идеальной юстировке **азимутальных дыр нет** — соседние секторы перекрываются на **~21°**.

### 3.2 Швы (диагонали) — пониженная чувствительность

На **диагоналях** (NE, SE, SW, NW) цель на краю FOV **двух** камер сразу:

| az диагонали | el | Проблема |
|--------------|-----|----------|
| 45°, 135°, 225°, 315° | **25°…55°** | Дисторция, малый px/град, риск **пропуска motion** на субпотоке 720p |
| те же | **55°…75°** | Overlap есть; детекция **нормальная** |
| зенит | **>85°** | Все 4 Sky видят (угол до оси ≤25° < 52.5°) |

**Оценка шва (el = 40°, az = 45°):**  
угловое расстояние до осей N и E ≈ **40–50°** от центра кадра → **<8 px** на цель 0.5 m @ 100 m → зона **M**, не **A**.

```text
        N
    ┌───┬───┐
    │ M │ M │     M = motion возможен, но хуже SNR
  W ├─░─┼─░─┤ E   ░ = шов (диагональ), el 25-55°
    │ M │ M │
    └───┴───┘
        S
```

### 3.3 «Зонт» куба — ближняя зона

Корпус куба перекрывает лучи **под** плоскостью верхней грани.

| Зона | Геометрия (ориентир) | Код |
|------|----------------------|-----|
| Над площадкой куба | горизонтальное расстояние **< 1 m** от оси, **h < 2 m** | **A/M** |
| Сквозь грань куба | el < 10°…15° в сторону «за» гранью | **A** |

Для цели **h = 10 m** над центром: el ≈ 83°, R_slant ≈ 10 m — **видна** Sky.  
Для **h = 3 m**, r_horizontal = 0.5 m: el ≈ 80° — на грани видимости.

### 3.4 Низкое небо (горизонт)

Sky смотрят **вверх**; при el **< 12°…18°** (зависит от tilt и высоты крепления):

- небо у линии горизонта **слабо** или не попадает в кадр;
- здания/деревья дают ложные motion.

| el | Зона |
|----|------|
| < 12° | **A** для целей на фоне горизонта |
| 12°…25° | **M** (motion нестабилен) |
| > 25° | штатная зона Sky |

### 3.5 Сводка Sky

| ID | Мёртвая / слабая зона | az | el | Митигация |
|----|------------------------|-----|-----|-----------|
| **S1** | Диагональные швы | 45°, 135°, 225°, 315° | 25°…55° | overlap **25%**, tilt **20°**, поднять detect FPS |
| **S2** | Зонт куба | все az | h<2 m над кубом | PTZ wide home, турель |
| **S3** | Низкое небо | все az | < 12°…18° | Принять; не целевой сегмент |
| **S4** | Край FOV / vignetting | край 105° | любой | Калибровка, отбраковка bbox |

## 4. PTZ × 4 — мёртвые зоны

### 4.1 Home (зенит), wide 1×

PTZ в углах куба, home = **▲**. Ось проходит через угол, не через центр.

| Зона | Описание |
|------|----------|
| **P1** «Кольцо между PTZ» | Над центром куба: az по диагоналям, el **70°…90°** — цель в **стыке** 4 конусов; на wide **без наведения** возможен **M** без класса |
| **P2** Под PTZ | Стойка/корпус PTZ, el < 5° локально | **A** |

При **активном наведении** P1 исчезает для выбранной цели.

### 4.2 Статическое покрытие (без slew)

Одновременно **2 PTZ** ведут primary/secondary; **2 PTZ** в home:

| az сектор | PTZ без slew | Риск |
|-----------|--------------|------|
| Угол куба (NE…) | 1 PTZ в home смотрит в угол | **M** до cue |
| Противоположный сектор | 0 PTZ наведены | только Sky |

### 4.3 Зум tele (25×)

HFOV **2.6°** — вне узкого конуса **нет класса**:

| ID | Зона | Код без наведения |
|----|------|-------------------|
| **P3** | Вне оси PTZ на tele | **M** (только Sky) |
| **P4** | Внутри FOV tele | **C/G** |

### 4.4 Триангуляция (геометрия)

| Условие | Эффект |
|---------|--------|
| Угол между лучами 2 PTZ **< 20°** | **G** нестабильна, range explode |
| Угол **20°…30°** | **G** с низким `pos_confidence` |
| Угол **30°…120°** | **G** штатная |
| Цель **над центром** | Лучи сходятся, угол малый → **P5** |

**P5 — «столб над кубом»:** az любой, el > 80°, R < 30 m — триангуляция **деградирует**; класс по PTZ возможен, координаты — с оговоркой.

### 4.5 Сводка PTZ

| ID | Зона | Митигация |
|----|------|-----------|
| **P1** | Диагонали у зенита, home | orchestrator: cue nearest PTZ |
| **P3** | Вне tele FOV | slew + zoom auto |
| **P5** | Малый угол лучей / над центром | 3-й PTZ, фильтр Калмана, `pos_confidence` |
| **P6** | Только 1 PTZ в зоне | не выдавать geo; ждать 2-ю PTZ |

## 5. Комбинированная карта (Sky + PTZ)

| Регион | el | R (дрон) | Sky | PTZ | Итог |
|--------|-----|----------|-----|-----|------|
| Рабочий объём | 25°…75° | 30…500 m | да | slew | **G** |
| Диагональные швы S1 | 25°…55° | 50…150 m | слабо | cue | **M→C** |
| Зенит / над кубом P5 | >80° | <30 m | да | geo слабая | **M/C** |
| Горизонт S3 | <15° | >200 m | нет | редко | **A/M** |
| Ближний купол | >60° | <15 m | частично | да | **C**, турель |

## 6. Турель (опционально) — мёртвые зоны

См. [turret-ballistics.md](turret-ballistics.md).

| ID | Зона | R / геометрия |
|----|------|----------------|
| **T1** | Слишком близко | R < **R_min** (~10 m) |
| **T2** | Вне дальности | R > **50 m** |
| **T3** | За кубом | LOS перекрыт корпусом |
| **T4** | Вне сектора az | механический упор / SAFE |
| **T5** | Нет локального TRACK | цель не в FOV камеры турели |

Турель **не закрывает** S1/S2 автоматически — нужна **позиция** вне зонтика куба.

## 7. Количественные ориентиры (полярная сетка)

Оценка для **юстированного** комплекта v1. «% неба» — доля твёрдого угла **4π** стерадиан; грубо, без учёта рельефа.

| Зона | Доля неба (ориентир) | Код |
|------|----------------------|-----|
| Полное покрытие motion (≥1 Sky) | **~88…92%** el>15° | M+ |
| Стабильный motion (≥12 px, не шов) | **~75…85%** | M |
| Класс PTZ после slew | **~60…70%** (зависит от политики 2 PTZ) | C |
| Гео 2× PTZ confidence >0.7 | **~50…65%** | G |
| Турель FIRE | **~5…8%** (купол R 10…50 m) | T |

Точные цифры — только после **цифрового моделирования** или полевой карты; использовать как порядок величин.

### Швы S1 — угловая ширина

```
Ширина зоны пониженной чувствительности на диагонали:
  w_seam ≈ max(0°, 90° - HFOV + overlap%×HFOV)
         ≈ max(0°, 90° - 105° + 21°) = 6° (при overlap 20%)

При overlap 15%: w_seam ≈ 11°  → риск выше
```

Рекомендация: **overlap ≥ 22%** или **tilt 20°** на стенде.

## 8. Митигации (чеклист)

### Монтаж / калибровка

- [ ] Юстировка Sky: overlap на макете **≥20%** по ярким звёздам/маяку
- [ ] Проверка швов S1 на el 30°, 45°, 60° по диагоналям
- [ ] PTZ home = зенит, `base_az` по GPS+компас
- [ ] Таблица zoom FOV для tele

### ПО (monitor-core)

- [ ] `sky_watch`: склейка треков на швах (один `target_id` на overlap)
- [ ] `orchestrator`: при треке в az 45°±15° и el 25°…55° — **приоритет cue PTZ**
- [ ] `geolocate`: не публиковать geo при угле лучей <25°; флаг `pos_confidence`
- [ ] Политика **3-я PTZ** для целей над центром (P5)

### Опционально

- [ ] Турель вне оси куба (смещение 2…5 m) — закрыть T3, S2
- [ ] Fisheye (alternatives) — убрать S1, другая дисторция
