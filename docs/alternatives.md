# Отложенные варианты (не v1)

Версия комплекта **v1** использует **4× sky fixed + 4× PTZ ONVIF**.  
Ниже — альтернативы для возможного v2, не закупать в рамках v1.

---

## Fisheye вместо 4× Sky

| | Fisheye | 4× Sky (v1) |
|---|---------|-------------|
| Модель | Dahua DH-IPC-EBW81242-AS-S2 | DS-2CD2T47G2-L × 4 |
| Порты | 1 | 4 |
| ПО | Проще (1 поток) | Склейка overlap |
| Дисторция | Высокая, dewarp | Ниже |
| Цена | ~45k | ~44k |

---

## DIY: bullet + ESP32 + шаговики

| | DIY | PTZ v1 |
|---|-----|--------|
| Порты | 8 (камера+ESP32) | 4 |
| Зум | 4–8× bullet | 25× |
| Время | 100+ ч | Недели |
| Улица | Своя герметизация | IP66 завод |

Прошивка: `firmware/ptz-controller/` — заготовка, не в эксплуатации v1.

---

## MQTT / Mosquitto

В v1 PTZ управляется **ONVIF** напрямую из core.  
MQTT планировался для ESP32 — **не разворачивается** в v1.

---

## Когда пересмотреть

- Нужна модульная смена только камеры без PTZ-корпуса
- Требуется субградусная точность углов без люфта PTZ
- Бюджет PTZ недоступен (тогда DIY — осознанный компромисс)
