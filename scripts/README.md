# Scripts

## Иллюстрации документации

**Активный:** [`compose-diagrams.py`](compose-diagrams.py) + базы в `docs/images/_base/`.

```bash
pip install pillow
npm run images
```

Полная политика: [docs/diagram-generation.md](../docs/diagram-generation.md).

## Deprecated

`deprecated/write-svgs.mjs` и `deprecated/svg2png.mjs` — старый SVG pipeline (ломает кириллицу, плоский стиль). **Не использовать** для `docs/images/`.
